# For Usha — A Sincere Apology

A private-in-spirit, public-link romantic page made for Usha. It includes:

- a 3–2–1 opening countdown;
- an interactive Cupid bow that works with mouse, touch, and keyboard;
- a blooming-rose reveal;
- floating hearts following mouse and touch;
- six original, unedited photos;
- three chat-memory screenshots;
- a personal apology letter; and
- direct playback of the supplied “Cinnamon Girl” audio from 00:06, with a
  play/pause control and a gentle fade-in.

## GitHub Pages

This is a static site. In the repository settings, open **Pages**, select
**Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.

## Privacy

The page asks search engines not to index it, but anyone with the public URL can
still view it. The site contains no analytics, forms, cookies, or data collection.
